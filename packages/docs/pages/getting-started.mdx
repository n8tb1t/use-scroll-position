# Get started

Need reliable scroll data for `animations`, `lazy loading`, or `sticky UI`? 

`@n8tb1t/use-scroll-position` gives you a `lightweight`, `tree-shakable` set of `hooks` that detect scroll position for the `viewport` or any `element` inside it — making scroll-driven `UX` easy to build.

## [useWindowScrollPosition](/use-window-scroll-position)
Track the global window scroll position or a specific element position by attaching the returned ref. 
Supports detecting when the viewport or element reaches the top or bottom.

## [useBodyScrollPosition](/use-body-scroll-position) 
Like useWindowScrollPosition, but uses a different detection method under the hood.

## [useOverflowScrollPosition](/use-overflow-scroll-position)

Track scrolling inside an overflow container. Provides both rootRef (for the container) and targetRef (for a child element) to detect scroll position and top/bottom reach within that container.
